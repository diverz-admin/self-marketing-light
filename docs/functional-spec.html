00이 문서를 읽는 법

모든 기능에는 구현 등급이 붙어 있습니다. 등급은 “완성도”가 아니라 “무엇이 남았는가”를 가리킵니다.

등급의미남은 일
AUI + DB / 서버액션 연동 완료. 실제로 동작함없음 또는 보강
BUI 완성 + 계산식·검증 로직 확정. 저장소만 목업(localStorage / setTimeout)백엔드 연결만
CUI만 존재. 핸들러 없음 또는 alert() 스텁기능 설계 + 구현
D라우트는 있으나 네비게이션에서 도달 불가, 또는 데드코드연결 또는 삭제 판단

영역별 현황

05비즈니스 규칙 정본

계산식

리워드 주문금액    = 일 작업량 × 매체 단가
리워드 연장금액    = 일 작업량 × 연장일수 × round(기존 주문금액 / 기존 일작업량)
리뷰 주문금액      = 유형 단가 × (발행일수 × 일발행량)   또는   유형 단가 × 모집인원
포인트 충전 입금액 = floor(요청 포인트 × 1.1)              // 부가세 10%
광고비 환급액      = round(월 집행액 × 요율)               // 10% / 7% / 5% / 3% / 0%
캠페인 진행률      = round(완료건수 / 총건수 × 100)
보장형 진행률      = min(순위 5위 이내 유지일수 / 25 × 100, 100)

제약 규칙

  • 최소 충전 10,000P
  • 리워드 최소 구동 3일, 연장 시 일 작업량 최소 10 (10 단위)
  • 리뷰 발행 일수 1~7일
  • 순위 조회 상한 300위
  • 리뷰 수정 요청 시 키워드 변경 불가
  • 당일 접수 마감 13:30
